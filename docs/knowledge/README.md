# Knowledge base

Markdown files the local chatbot (`quant_os_core.knowledge`) and the MCP `knowledge_search`
tool retrieve from. Keep each section focused under a `##` heading: one heading becomes one
retrievable chunk. Write in your own words and name sources for rulings and data; do not paste
copyrighted text. After adding a file, add a retrieval case to
`packages/core/tests/knowledge/test_rag_and_mcp.py`.
